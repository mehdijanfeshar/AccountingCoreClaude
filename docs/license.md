# لایسنس (قفل تسویه‌حساب)

فایل آفلاین امضاشده (RSA-SHA256). کد: `backend/src/Accounting.Api/Licensing/`، پنل توسعه‌دهنده: `backend/tools/Accounting.LicenseStudio`.

## رفتار
| وضعیت | چه می‌شود |
|---|---|
| تا تاریخ انقضا (`Valid`) | عادی |
| پس از انقضا تا `graceDays` (`Grace`) | عادی + هدر `X-License-Warning` + بنر زرد در UI |
| پس از مهلت / فایل نبود / امضای نامعتبر / واحد بی‌مجوز (`ReadOnly`) | هر درخواست نوشتن (POST…) → ۴۰۳ با `code=license_readonly`؛ GET آزاد؛ POSTهای انتهای `/preview` `/print` `/search` `/export` آزاد |

دو نوع لایسنس: **کل نصب** (یک تاریخ) یا **به‌تفکیک واحد** (فهرست کد واحد + تاریخ هر کدام؛ واحدِ بیرون از فهرست فقط‌خواندنی). واحدِ هر درخواست = `X-Vahed-Code` یا واحد خود کاربر (درستی هدر را `IUnitScopeResolver` جدا می‌سنجد). تطبیق واحد دقیق است، نه زیرمجموعه.

فایل هر دقیقه بازخوانی می‌شود ⇒ تمدید بدون ری‌استارت. عقب‌بردن ساعت سرور اثر ندارد (`license.lic.lastseen`).

## کانفیگ API (`appsettings.json`)
`License:Enforce` (پیش‌فرض `false` ⇒ توسعه آزاد؛ در استقرار مشتری `true`)، `License:Path` (پیش‌فرض `license.lic` کنار برنامه).

## پنل توسعه‌دهنده (روی سیستم خودتان، نه سرور مشتری)
```
dotnet run --project backend/tools/Accounting.LicenseStudio
```
سپس `http://127.0.0.1:5300`. داده در `LICENSE_STUDIO_DIR` (پیش‌فرض `D:\AiProj\LicenseKeys`): `private.pem` (کلید خصوصی) و `registry.json` (مشتری‌ها و تاریخچهٔ صدور، شامل خود فایل‌ها). از این پوشه پشتیبان بگیرید.
- فهرست مشتری‌ها با نزدیک‌ترین انقضا، رنگ وضعیت، فیلتر «نزدیک انقضا / مهلت / منقضی».
- «تمدید / صدور»: کل نصب یا به‌تفکیک واحد، دکمه‌های +۶ ماه/+۱ سال، مهلت ارفاقی، یادداشت؛ فایل `.lic` بلافاصله دانلود می‌شود.
- تاریخچهٔ هر مشتری با دانلود دوبارهٔ هر فایل.
- فقط روی localhost؛ API فقط با هدر `X-Studio`.

فایل را به مشتری بدهید؛ مدیر ستاد او در `/base/license` بارگذاری می‌کند، یا جای `license.lic` کنار برنامه می‌گذارید.

## UI (ریپوی جدا)
- `/base/license` (اطلاعات پایه، فقط مدیر ستاد): وضعیت، جدول واحدها (در حالت به‌تفکیک واحد)، «بارگذاری فایل لایسنس» ⇒ `POST /api/license/upload` (فقط `FINANCIAL CORE SETAD ADMIN`؛ فایل با امضای نامعتبر ذخیره نمی‌شود؛ در حالت فقط‌خواندنی هم کار می‌کند).
- بنر بالای همهٔ صفحه‌ها: ≤۳۰ روز تا انقضا (آبی)، مهلت ارفاقی (زرد)، فقط‌خواندنی (قرمز)؛ با `Enforce=false` هیچ.

## کلید
کلید خصوصی هرگز در ریپو یا نزد مشتری نرود. گم شود ⇒ کلید جدید بسازید و کلید عمومی را در `LicenseService.PublicKeyBase64` عوض و نسخهٔ جدید به همهٔ مشتری‌ها بدهید (کلید فعلی با `openssl`/`RSA` قابل ساخت است؛ ابزار keygen حذف شد).

## محدودیت‌ها
- مشتری با دسترسی به سرور می‌تواند DLL را دست‌کاری کند؛ این لایسنس جلوی استفادهٔ عادی/فراموشی را می‌گیرد، نه کرک.
- فقط تاریخ انقضا؛ کنترل ماژول/تعداد کاربر پیاده نشده.
